# Attribution

ReelQuotes is built from two openly-licensed data sources. No IMDb data is
scraped or redistributed.

## Movie index — Wikidata (CC0)

`data/movies.json` is generated by SPARQL queries against
[Wikidata](https://www.wikidata.org/) (`scripts/build-pool.ts`) covering
both films and TV series. Wikidata content is released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
(public domain) — no attribution is legally required. We credit it here
anyway. The `id` field is each title's IMDb identifier (Wikidata property
P345), used solely to construct an outbound link to the title's public IMDb
page on the round-result screen; no IMDb content is fetched.

## Quotes — English Wikiquote (CC BY-SA)

`data/quotes.json` is generated from [English Wikiquote](https://en.wikiquote.org/)
page wikitext via the MediaWiki API (`scripts/build-quotes.ts` +
`lib/wikiquote-parse.ts`).

Wikiquote text is licensed under the
[Creative Commons Attribution-ShareAlike License](https://en.wikiquote.org/wiki/Wikiquote:Copyright)
(CC BY-SA; some older contributions are additionally available under the
GFDL). In accordance with that license:

- **Attribution.** Each quote originates from the English Wikiquote page
  whose title is recorded in the `wqTitle` field of the corresponding
  `data/movies.json` entry. The canonical URL for a source page is
  `https://en.wikiquote.org/wiki/<wqTitle>` (spaces as underscores). Page
  histories list individual contributors.
- **Indication of changes.** The quote text is transformed, not reproduced
  verbatim as published: MediaWiki markup is stripped, dialogue is
  restructured into a normalized JSON shape, character/speaker names are
  anonymized at request time, and only a capped random subset (≤20) of each
  page's quotes is retained.
- **ShareAlike.** The quote content in `data/quotes.json` remains licensed
  under CC BY-SA. Anyone redistributing that file (or a derivative of it)
  must do so under the same terms and preserve this attribution.

The application **source code** is separately licensed under the MIT License
(see [`LICENSE`](./LICENSE)); the CC BY-SA obligation attaches only to the
quote *content*, not the code.
